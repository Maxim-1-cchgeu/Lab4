# Домашнее задание к работе 4
## Условие задачи
Три груза (A, B, C кг) можно погрузить в контейнер, если вес каждого из них кратен пяти. Запишите условие, при котором диспетчерская система дает разрешение на погрузку.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить переменные:
   - **A** — первый груз.
   - **B** — второй груз.
   - **C** — третий груз.
3. Составить условие при помощи операторов if и else:
4. **Конец**

## 2. Реализация программы

```C
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main()
{
    setlocale(LC_CTYPE, "RUS.UTF-8");

    int A, B, C;

    puts("Введите массу первого груза: ");
    scanf("%d", &A);

    puts("Введите массу второго груза: ");
    scanf("%d", &B);

    puts("Введите массу третьего груза: ");
    scanf("%d", &C);

    int condition = A % 5 == 0 
                    && B % 5 == 0
                    && C % 5 == 0;
    printf("Погрузка разрешена (1 - да, 0 - нет): %d\n", condition);
}
```
